책

옛날 책을 스캔하며 다시 읽기

6월부터 책 이야기가 부쩍 늘어납니다. 예전에 읽은 책에서 밑줄 친 부분을 옮겨 적고 스캔해서 네이버 클라우드에 올려 두는 작업을 매일 조금씩 했습니다. 스캔한 PDF에는 ocrmypdf로 글자를 입혀 보기도 했습니다.

다시 읽다가 틀린 곳을 찾으면 그냥 넘어가지 않았습니다. SI 개발서에 "ArrayList가 thread safe하다"는 문장이 있는 것을 보고 JavaDoc과 대조했고, 그 책이 Map과 List 위주로 짜인 이유를 당시 서버 재시작 시간과 피드백 주기로 설명했습니다.

  • 2020-06-16옛날에 읽은 책을 스캔해서 네이버 클라우드에 올려두니 문득 생각나는걸 찾아볼때 무척 편하다.
  • 2020-06-20하루에 한 10분~20분정도씩 시간을 써서 옛날에 읽었던 책에서 인상싶은 부분을 옮겨적은 후 스캔을 하고 있다.
  • 2020-06-30'ArrayList 가 thread safe 하기 때문에'라고 적어놓은 것이 우선 흥미롭다.
일

Spring JDBC와 SQL을 어디에 둘 것인가

spring-data-jdbcnaver/spring-jdbc-plusMyBatisGroovy

생성자 기반 RowMapper, 메서드 이름으로 쿼리를 만드는 기능처럼 Spring JDBC 쪽 변화를 계속 따라갔습니다. 10달 전에 올린 이슈가 그제야 'INVESTIGATING' 상태로 바뀐 일도 적었습니다. 5월에는 소속 조직이 공개한 naver/spring-jdbc-plus 저장소를 소개했습니다.

SQL을 MyBatis XML 대신 Groovy 문자열로 관리하자는 주장도 이 해에 나옵니다. 근거는 배워야 할 문법이 따옴표 3개 하나뿐이라는 것입니다.

  • 2020-06-24Groovy로 SQL 관리를 하기 위해 알아야하는 문법은 따옴표 3개, 딱 하나이다.
  • 2020-09-03BeanPropertyRowMapper가 setter가 필수라서 마음에 안 들었는데, 생성자 기반으로 할수 있는 클래스가 새로 생겼구나
  • 2020-11-19한 10달전에 올렸었는데, 어제 'INVESTIGATING' 상태로 바뀜.

GraalVM Native Image, Fiber, Leyden 같은 JDK 소식도 한두 줄 메모와 함께 8개쯤 올렸습니다. 2월 1일에는 작년에 사내 연재로 쓰려다 못 쓴 목록(Helidon, Micronaut, Quarkus, ZGC 등)을 공개하고 4월쯤 다시 시작하겠다고 했지만, 이 해 글에서 연재가 시작된 흔적은 없습니다.

재택

모니터암과 폰 웹캠

3월 말부터 화상회의가 늘었고, 4월 5일에 모니터암, 휴대용 모니터, 폰을 웹캠으로 쓰는 DroidCam으로 작업 환경을 바꿨습니다. Linux 데스크톱에서 카카오톡은 scrcpy로 폰 화면을 띄워 썼습니다. 12월에는 재택근무가 더 피곤한 이유를 스스로 추측해 봤습니다.

  • 2020-04-05재택근무가 길어지니 작업 환경 개선에 이래저래 투자를 하게 된다.
  • 2020-12-14재택근무 후 더 피곤한 날이 많은 이유가 출퇴근하면서 멍 때리는 시간이 없어서여서 인것 같다.
도구

요구사항부터 적고 도구를 고른다

5월에는 발표 도구에 바라는 조건 5가지를 번호를 매겨 적었고, 7~8월에는 Hugo, Netlify, 여러 Git 호스팅의 웹 편집 기능을 비교해 순위까지 매겼습니다. 9월 3일에는 일기 사이트 diary.benelog.net을 만들었습니다. 페이스북에는 쓸모 있는 정보만 남기려고 일기를 따로 뺀 것입니다.

  • 2020-05-08아직 내 요구사항을 완전히 만족시키는 건 없다.
  • 2020-08-04GitLab + Netlify + Hugo + Forestry + Disqus + GA
  • 2020-09-03나도 유용한 정보만 SNS에 남기기 위해서 일기장을 만들어보았다.

소속 조직(Platform Labs, 플라즈마 프로젝트팀)의 채용 공고를 4월, 10월, 11월에 올렸습니다. 5월에는 조직 이름이 처음 외부 자료에 나왔다고 반가워했습니다. 8월 31일에는 큰 회사와 작은 회사 중 어디가 성장에 좋으냐는 질문에 회사 규모보다 어떤 시스템을 만드느냐가 중요하다고 길게 답했습니다.

  • 2020-05-22'네이버 플라즈마 프로젝트팀' 이라는 우리 조직 이름이 처음으로 외부 공개된 자료인듯..

말투

비유를 코드로 바꿔 보기

"우유 하나 사 오고, 아보카도가 있으면 6개 사 와"라는 농담을 addMilkToCart(1) 코드로 옮겨 컴파일 에러 아니면 우유 7개라고 풀었습니다. 드라마 '나의 아저씨'의 외력과 내력 대사는 서버 개발 버전으로 바꿔 썼습니다. 그러면서도 다른 분야에 소프트웨어 개발을 빗대는 비유는 전체적으로 맞지 않는 부분이 많다고 선을 그었습니다.

  • 2020-09-24부하(stress)와 처리율(throughput)의 싸움
  • 2020-09-25프로그래머라면 컴파일 에러 혹은 7개를 사와야 한다.
  • 196 회문수를 새벽에 찾아보다 "난 왜 다른 일 하려고 새벽에 일어났다가"
  • "안녕하세요. 판매자 검색 API서버입니다."로 메일 답장 쓰기
  • "미래는 이미 지나갔다. 단지 언제 돌아올지 모를 뿐이다."를 직접 지어냄
  • 휴가에 노트북 하나만 들고 가서 "다른 사람은 알지 못하는 행복감"
정리

옛 책을 스캔하고, Spring JDBC 이슈를 지켜보고, 재택 장비를 손본 해. 12월 31일에는 이 해를 "긴 터널을 벗어나지 못한 한해"라고 적고 5km 달리기와 책 원고 마무리를 내년 목표로 꼽았습니다.

5월에는 외부 강연료를 전액 기부했다고 밝혔고, 4월에 "올해 SpringOne 참석 예정 (10년만인가...)"이라고 썼지만, 이 해 공개 글에 참석 후기는 없습니다.

2020년에 facebook.com/benelog에 전체 공개로 올린 글 107개를 바탕으로 Claude Code(Claude Opus)가 정리했습니다. 친구 공개 글, 남의 담벼락에 쓴 글, 같은 링크가 두 번 기록된 항목은 뺐습니다. 인용문은 원문의 맞춤법을 그대로 두었고, 일부는 가운데를 줄였습니다(…).
