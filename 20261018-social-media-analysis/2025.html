2025년의 페이스북

3월에는 "회사에서 코딩을 안 하다보니" AI 도구를 남의 후기로만 접했는데, 연말에는 AI로 테스트를 만들며 Spring Batch에 기능 PR을 올렸습니다. 12월 이사를 앞두고 종이책을 스캔한 해이기도 합니다.

3월 글은 관찰자의 자리에서 시작합니다. 이후 Copilot의 IntelliJ agent 모드, Gemini Code Assist, Antigravity 같은 도구 소식을 계속 공유했고, 7월에는 같은 글 초안을 Gemini, ChatGPT, Perplexity, 하이퍼클로바 X에 맡겨 비교했습니다. 12월 7일에는 AI에게 테스트 코드를 맡기면서 범위를 알려 주려고 중간 commit과 git 스테이징 영역을 쓰는 방법을 적었습니다.

관심은 도구보다 일하는 환경 쪽에 있었습니다. 7월에 인용한 문장이 이를 보여 줍니다.

  • 2025-07-16'신규 입사자가 일하기 어려운 회사면 AI도 일하기 어려운 회사다'
  • 2025-12-07AI에게 집중해야할 코드의 범위를 섬세하게 알려주기 위해서 중간 commit이나 git 스테이징 영역을 잘 활용하면 좋을듯..
오픈소스

세 AI가 같은 오답을 낸 문서

Spring Boot 문서의 spring.batch.job.enabled 설명이 틀린 것을 두고 Gemini, ChatGPT, Perplexity에 물었더니 셋 다 문서를 따라 틀리게 답했습니다. 직접 PR을 올려 7월에 반영됐습니다. 11월부터는 Spring Batch에 문서 수정이 아닌 기능 추가 PR, 버그 수정 PR, 테스트를 포함한 PR을 차례로 올렸고, 12월 v6.0.1에 패치 2건이 들어갔습니다.

  • 2025-07-02반영됨. 다음 번에는 'the the'나 고쳐야지.
  • 2025-11-01오랜만에 문서 오류 수정이 아닌 기능 추가 Pull request를 날려봤음.
  • 2025-12-18이번 버전에 기여한 컨트리뷰터가 8명인데, 나를 포함하여 그 중 한국 사람이 3명이라는 점도 반갑다.
일의 미래

먼저 온 미래

7월 4일, 회사 일이 바쁜 와중에 잠을 줄여 가며 읽은 책을 일찌감치 "올해의 책"으로 확정했습니다. 8월에는 '먼저 온 미래' 감상문을 블로그에 쓰고, 페이스북에 올린 요약에 AI가 더 잘하는 시대에 사람이 할 일을 이렇게 적었습니다. 이세돌, 하용호 인터뷰도 같은 질문으로 인용했습니다. 걱정과 낙관이 글마다 번갈아 나오고, 어느 한쪽으로 정리하지 않았습니다.

  • 2025-08-08AI가 더 '탁월한 능력'을 보여지는 시대에 사람의 핵심가치는 스스로의 이해를 바탕으로 공감가는 서사를 담아 정보와 판단을 전달하는 능력입니다.
  • 2025-08-23작년에 AI 코딩 도구의 발전이 이렇게 빠를 것이라고 예상한 사람도 거의 없었을듯하다.
책

이사 전에 종이책을 스캔하다

업체에 맡긴 스캔본은 용량이 너무 컸고, 직접 돌려 본 Tesseract OCR은 품질이 마음에 들지 않았습니다. 7월에는 구상만 AI에게 이야기해 README를 받은 pdf-refinery 저장소를 만들었습니다. 10월에는 12월 이사를 앞두고 짐을 줄이려고 종이책을 많이 스캔하면서 알PDF의 OCR이 쓸 만하다고 적었습니다.

책 속 사실이 틀리면 연도부터 확인합니다. 5월에는 "MyBatis 다음에 Hibernate가 나왔다"는 설명을 반박했고, 6월에는 '은탄환' 비유의 유래가 책에 잘못 적혔다고 썼습니다.

  • 2025-05-24그런데 Hibernate는 MyBatis의 전신인 iBatis와 같은 해인 2001년에 시작되었다.
  • 2025-06-20동영상보다는 책으로 지식을 얻는 것을 선호한다.
  • 2025-10-1712월달로 예정된 이사를 준비하면서, 짐을 줄이기 위해 근래 종이책을 많이 스캔하고 있다.
시간

남들 유튜브나 넷플릭스 볼 시간에

7월 11일 세미나를 듣고 앞으로 1~2년 동안 여가 활동이 얼마나 쓸모 있는지를 더 엄격하게 따지기로 했습니다. "남들 유튜브나 넷플릭스 볼 시간에"라는 표현은 7월과 11월에 두 번 나옵니다. 11~12월의 Spring Batch PR들이 이 다짐을 실행한 결과로 보이지만, 본인이 그렇게 연결해 쓰지는 않았습니다.

  • 2025-07-11앞으로 한 1~2년 동안의 여가 시간에 하는 활동의 유익성을 더 엄격하게 평가하기로했다.
  • 2025-11-29남들 유튜브나 넷플릭스 볼 시간에 여가 선용했다고 생각하자.
  • 세 AI 중 Gemini만 잘못을 인정하자 "사회 생활을 Gemini에게 배워야겠다."
  • 옛 기술(PHP4, Model1 JSP, Struts)을 체험하는 "민속촌 투어" 해커톤
  • 멀티태스킹의 예시로 박경락의 3군데 동시 럴커 드랍
  • 썸머타임 도입 움직임이 있으면 "데모라도 할 각오"
정리

관리 일 때문에 코딩에서 멀어졌다가, AI 도구와 함께 주말에 다시 코드를 고치기 시작한 해. 연말의 Spring Batch 기여가 그 결과입니다.

12월 27일 글은 이 해를 한 줄로 정리했습니다. "코딩이란 무엇일까, 개발이란 무엇일까... 이런 생각들을 많이 했던 한 해였다."

2025년에 facebook.com/benelog에 전체 공개로 올린 글 71개를 바탕으로 Claude Code(Claude Opus)가 정리했습니다. 친구 공개 글, 남의 담벼락에 쓴 글, 같은 링크가 두 번 기록된 항목은 뺐습니다. 인용문은 원문의 맞춤법을 그대로 두었고, 일부는 가운데를 줄였습니다(…).
